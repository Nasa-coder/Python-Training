# Naming exercise

### Lesson
Good names help you understand code months later. Always ask: what does this
value represent? What unit is it in? Is there a better word than `x` or `a`?

### Task
Rename each weak variable name with a clearer one and explain why.

1. total_hours_worked = total hours worked 
2. user_name = user name
3. price_in_dollars = price in dollars
4. tags = tags
5. retry_count= retry count

beacuse using snake_case makes reading much better and also if someone opens your code he or she will understand without guessing

1. total_hours_worked — clearly describes the total hours worked.
2. user_name — clearly describes the user's name.
3. price_in_dollars — clearly describes the price and its unit.
4. tags — clearly describes what the list contains and avoids using the built-in name `list`.
5. retry_count — clearly describes the number of retries.
